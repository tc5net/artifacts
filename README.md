# artifacts

Sejda is a PDF library/service. It comes in a few forms:

  - Sejda SDK — an open-source Java library for PDF manipulation (merge, split, compress, convert, edit, etc.)
  - Sejda Console — a command-line tool built on the SDK
  - Sejda.com — a web-based PDF tool using the same underlying library

  It's built on top of Apache PDFBox and iText/Bouncy Castle, and is commonly used in Java/JVM projects that need PDF processing without a heavy commercial dependency.
